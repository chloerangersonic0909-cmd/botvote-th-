# BotVote

เว็บไซต์ภาษาไทยสำหรับค้นหา เพิ่ม และรีวิวบอท Discord

## เปิดใช้งานด้วย GitHub Pages
1. เปิดแท็บ **Settings** ของ repository
2. ไปที่ **Pages**
3. ใน **Build and deployment** เลือก **Deploy from a branch**
4. เลือก branch `main` และ folder `/ (root)` แล้วกด **Save**
5. รอสักครู่ แล้วเปิด URL ที่ GitHub Pages แสดงให้

## คุณสมบัติ
- เพิ่มบอทด้วยชื่อ, Discord Client ID, ลิงก์เชิญ และคำอธิบาย
- ค้นหาและเรียงรายการ
- ปุ่มถูกใจ/ไม่ถูกใจ และรีวิว
- รองรับมือถือและภาษาไทย
- ไม่ขอ Bot Token

## ข้อจำกัดสำคัญ
รุ่นนี้เป็นเว็บ static ที่เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์เท่านั้น ดังนั้นรายการบอทและรีวิวจะไม่ซิงก์ข้ามอุปกรณ์หรือผู้ใช้ และอาจหายเมื่อข้อมูลเบราว์เซอร์ถูกลบ หากต้องการฐานข้อมูลกลาง ต้องเพิ่ม backend/database และระบบป้องกันสแปมก่อนเปิดให้ชุมชนใช้งานจริง
